# Carbon Finance Pro Dashboard

A high-performance, premium financial dashboard built with Next.js 16, Tailwind 4, and Framer Motion.

## 🚀 Key Features
- **Modern Tech Stack**: Next.js 16 (App Router), Tailwind CSS v4, TypeScript.
- **Premium UI/UX**: Technical Brutalist design with sharp geometry, glassmorphism, and Cyber Lime accents.
- **Interactive Analytics**: Dynamic Recharts implementation for cash flow and mini sparklines.
- **AI-Powered Insights**: Smart alert system with financial score indicators.
- **Highly Responsive**: Fully adaptive layout for Desktop, Tablet, and Mobile.
- **Premium Performance**: Optimized animations with Framer Motion and server-side rendering.

## 🛠️ Tech Details
- **Styling**: Tailwind CSS v4 (CSS-first config).
- **Icons**: Lucide React.
- **Animations**: Framer Motion.
- **Charts**: Recharts.
- **State**: Zustand.
- **Fonts**: Outfit (Display) & Inter (UI).

## 📦 Getting Started
1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
3. Build for production: `npm run build`

## 🎨 Design System
- **Carbon Black**: `#0A0A0A` (Background)
- **Cyber Lime**: `#DFFF00` (Primary Action)
- **Electric Blue**: `#0066FF` (Revenues)
- **Signal Red**: `#FF3B30` (Expenses)
